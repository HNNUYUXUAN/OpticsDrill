# 题源与解答核验

现版题库依据《光学教程》（第六版）当前PDF，收录课程指定52题。题面保留完整原文及全部小问，排版作统一处理；3张原题图直接由PDF裁切。题意说明、解题模型及教材正文补充依据均放在解答中。

## 主要修订

- 1.7：按印刷32页式(1-35)从j=0起的干涉级次，二级取j=2，膜厚约710 nm。
- 1.16：按印刷48页式(1-41)，反射亮环r_j²=(j+1/2)λR，j=0,1,…。第19与20级间距约0.386 mm。
- 1.19：完整保留两个小问。间距0.0692 mm；解答补充条纹方向、重叠条件及中心相长条件，说明未给外口径的边界。
- 3.8：原题为凸面镜，眼到薄玻璃板24 cm，板到镜16 cm。
- 3.21：原题图在正文后页；物距5 cm沿轴向，物点位于组合对称轴上。
- 4.19与5.13：按原题检查能否分辨、透射偏振状态，评分目标对应原题所求。
- 5.9：原题未限定波片阶次；解答明确最薄解16.37 μm及其他阶次。
- 7.14：统一hc采用1239.84 eV·nm；8.1、8.2统一能量单位换算精度。

## 模型与正文依据

- 几何光学的近轴、理想器件和距离正号约定逐题列明。
- 4.2说明忽略镜眼距离、不同调节端点对应的镜度范围。
- 5.2按理想偏振选择以外每片另有10%透射损耗求解。
- 5.18沿用相邻题给出的黄光折射率差0.172，并说明忽略色散的近似。
- 7.12将1 W视为光辐射功率；若为耗电功率还需光转换效率。
- 7.14接触电势差的电极方向在解答中定义。
- 8.4题面仅给氦氖激光及单色性6×10⁻¹⁰。解答采用教材印刷333页（全本PDF349页）介绍的632.8 nm可见红线及窄带估计，得到约1.05 km；谱形与相干定义会影响系数。
- 8.1原题要求画能级图但未附图，应用中的能级SVG明确标为解答图。
